# Code of Conduct

## Our Pledge

We as contributors and maintainers pledge to make participation in Aestra a hassle-free, welcoming, and constructive experience for everyone, regardless of background, identity, or level of experience.

## Standards

- **Constructive Communication**: Focus on clear technical feedback and collaboration.
- **Respect**: Respect differing viewpoints, architectural proposals, and technical experiences.
- **Responsibility**: Act gracefully in resolving technical disagreements and code reviews.

## Scope

This Code of Conduct applies within all project spaces, including GitHub issues, pull requests, and discussions.
